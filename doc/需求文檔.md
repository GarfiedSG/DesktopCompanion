## 三、功能需求

### 3.1 寵物核心

#### 3.1.1 透明置頂窗口

- 無邊框：`Qt.FramelessWindowHint`
- 背景透明：`WA_TranslucentBackground`
- 永遠置頂：`Qt.WindowStaysOnTopHint`
- 不顯示在工作列：`Qt.Tool`
- 左鍵拖拽移動
- 透明區域點擊穿透
- 多螢幕與高 DPI 適配
- 記住上次位置、縮放、透明度

#### 3.1.2 動畫狀態機

```text
Idle    待機（播放當前待機動畫，可能附帶移動）
Click   被點擊反應
Drag    被拖拽
```

- 支援多個待機動畫，隨機切換
- 相同狀態或相同動畫之間切換**不**觸發交叉淡化（本期不做淡化）
- 同一動畫長時間循環時，首尾幀盡量一致
- **待機時原地不動，只有特定待機動畫（`move=true`）才附帶限定範圍內的移動**

#### 3.1.3 待機動畫調度

- **動畫自動掃描**：程式啟動時掃描 `文檔/animations/idle/` 下所有子資料夾。
  - 每個子資料夾代表一個待機動畫。
  - 每個子資料夾內必須有 `frame_*.png` 序列帧。
  - 每個子資料夾可選有 `anim.json` 配置檔。
  - 無需手動維護 config.json 的清單，也無需重新編譯。
- **每個動畫獨立配置**：載入動畫前先讀取該資料夾的 `anim.json`。
- **啟動行為**：程式啟動後，直接從所有 `enabled=true` 的動畫中**隨機選擇一個**作為初始待機動畫。
- **拖拽釋放行為**：拖拽放開滑鼠後，**隨機選擇一個** `enabled=true` 的動畫作為待機動畫。
- **切換間隔**：同一個待機動畫至少持續 **1 分鐘**（拖拽動畫除外）。
- **避免連續重複**：切換時排除當前動畫，不連續選擇同一個。
- **權重規則**：每個動畫的 `anim.json` 中 `weight` 值**越小，權重越高**。
  - `weight=1` 被選中的機率是 `weight=3` 的 3 倍。
  - `weight` 預設為 1，最小值限制為 1。
- **拖拽釋放後位置**：拖拽晴兒到新位置後放開，晴兒**停留在新位置**，不回到原位。
- **移動動畫的移動起點**：若切換到 `move=true` 的動畫，以**當前位置**為新移動起點。

#### 3.1.4 基礎互動

- 左鍵拖拽：移動晴兒
- 左鍵單擊：播放點擊動畫，播完回 Idle
- 右鍵選單：顯示/隱藏、鎖定、置頂、縮放、退出
- 系統托盤：顯示/隱藏、靜音、設置、退出
- 滾輪縮放、雙擊隱藏、全域快捷鍵（可選）

### 3.2 動畫資料夾與 anim.json

#### 3.2.1 資料夾結構

```text
文檔/animations/idle/
├─ idle_standing/
│  ├─ anim.json
│  ├─ frame_000.png
│  ├─ frame_001.png
│  └─ ...
├─ idle_walking/
│  ├─ anim.json
│  ├─ frame_000.png
│  └─ ...
└─ idle_cat/
   ├─ anim.json
   ├─ frame_000.png
   └─ ...
```

#### 3.2.2 anim.json 格式

```json
{
  "name": "站立呼吸",
  "enabled": true,
  "weight": 1,
  "move": false,
  "move_speed": 4,
  "move_range": 200
}
```

| 欄位 | 型別 | 預設 | 說明 |
| :--- | :--- | :--- | :--- |
| `name` | str | 資料夾名 | 顯示名稱 |
| `enabled` | bool | true | 是否啟用 |
| `weight` | int | 1 | 隨機選擇權重，**值越小權重越高** |
| `move` | bool | false | 是否附帶移動 |
| `move_speed` | int | 4 | 移動速度（像素/幀），僅 move=true 時有效 |
| `move_range` | int | 200 | 移動範圍（像素），僅 move=true 時有效 |

#### 3.2.3 掃描規則

- 掃描 `文檔/animations/idle/` 下所有子資料夾。
- 每個子資料夾必須包含至少一個 `frame_*.png`，否則跳過。
- 若有 `anim.json`，讀取並解析；缺失欄位用預設值補齊。
- 若無 `anim.json`，全部使用預設值。
- 若 JSON 解析失敗，使用預設值，不中斷掃描。

#### 3.2.4 暫時關閉某動畫

將該動畫的 `anim.json` 中 `enabled` 設為 `false` 即可。程式啟動後不會選中此動畫。

**緩存清理策略**：
- **保留範圍**：最近 7 天（含當天）
- **清理時機**：程式啟動時執行一次
- **清理方式**：讀取 `greeting_cache.json`，刪除日期早於 `今天 - 7 天` 的記錄
- **容錯**：JSON 解析失敗時直接重置為空對象
- **寫入格式**：`YYYY-MM-DD` 字符串比較

```python
import json
from datetime import datetime, timedelta
from pathlib import Path

CACHE_PATH = Path("greeting_cache.json")
KEEP_DAYS = 7

def cleanup_cache():
    if not CACHE_PATH.exists():
        return
    try:
        data = json.loads(CACHE_PATH.read_text(encoding="utf-8"))
    except (json.JSONDecodeError, OSError):
        CACHE_PATH.write_text("{}", encoding="utf-8")
        return

    cutoff = (datetime.now() - timedelta(days=KEEP_DAYS)).strftime("%Y-%m-%d")
    cleaned = {k: v for k, v in data.items() if k >= cutoff}

    if len(cleaned) != len(data):
        CACHE_PATH.write_text(
            json.dumps(cleaned, ensure_ascii=False, indent=2),
            encoding="utf-8"
        )
```
啟動時調用 `cleanup_cache()`。

## 五、技術要點

### 5.1 動畫自動掃描（AnimationLibrary）

```python
import json
import re
from pathlib import Path

DEFAULT_ANIM_CONFIG = {
    "name": None,
    "enabled": True,
    "weight": 1,
    "move": False,
    "move_speed": 4,
    "move_range": 200,
}


def natural_key(path: Path):
    return [int(t) if t.isdigit() else t.lower()
            for t in re.split(r"(\d+)", path.stem)]


class AnimationLibrary:
    def __init__(self, base_dir: Path):
        self.base_dir = base_dir
        self.idle_dir = base_dir / "文檔" / "animations" / "idle"

    def scan(self) -> list:
        animations = []
        if not self.idle_dir.exists():
            return animations

        for folder in sorted(self.idle_dir.iterdir()):
            if not folder.is_dir():
                continue

            frames = sorted(folder.glob("frame_*.png"), key=natural_key)
            if not frames:
                continue

            config_path = folder / "anim.json"
            anim = dict(DEFAULT_ANIM_CONFIG)
            if config_path.exists():
                try:
                    data = json.loads(config_path.read_text(encoding="utf-8"))
                    for k in DEFAULT_ANIM_CONFIG:
                        if k in data:
                            anim[k] = data[k]
                except (json.JSONDecodeError, OSError):
                    pass

            if anim["name"] is None:
                anim["name"] = folder.name

            anim["path"] = str(folder.relative_to(self.base_dir / "文檔"))
            anim["frames"] = [str(f) for f in frames]
            animations.append(anim)

        return animations

    def get_enabled(self) -> list:
        return [a for a in self.scan() if a.get("enabled", True)]
```

### 5.2 待機動畫調度（IdleScheduler）

關鍵設計：
- 啟動時隨機選擇一個啟用動畫。
- 拖拽釋放後隨機選擇一個啟用動畫。
- 同一動畫至少持續 `MIN_HOLD_SECONDS = 60` 秒。
- 權重計算：`weights = [1 / max(a.get("weight", 1), 1) for a in candidates]`。
- 排除當前動畫，避免連續重複。
- 候選為空時不切換，重新排程。

```python
import random
from PySide6.QtCore import QObject, QTimer, Signal


MIN_HOLD_SECONDS = 60


class IdleScheduler(QObject):
    switch_requested = Signal(dict)

    def __init__(self, base_dir, config):
        super().__init__()
        self.base_dir = base_dir
        self.config = config
        self.library = AnimationLibrary(base_dir)
        self.current_path = None
        self.timer = QTimer()
        self.timer.setSingleShot(True)
        self.timer.timeout.connect(self._pick_next)

    def start(self):
        self.timer.stop()
        self.current_path = None
        self.pick_random()

    def pick_random(self):
        """立即隨機選擇一個啟用動畫（不排除當前）。"""
        candidates = self.library.get_enabled()
        if not candidates:
            return
        weights = [1 / max(a.get("weight", 1), 1) for a in candidates]
        chosen = random.choices(candidates, weights=weights, k=1)[0]
        self.current_path = chosen["path"]
        self.timer.stop()
        self.switch_requested.emit(chosen)
        self._schedule_next()

    def _pick_next(self):
        candidates = [
            a for a in self.library.get_enabled()
            if a["path"] != self.current_path
        ]
        if not candidates:
            self._schedule_next()
            return
        weights = [1 / max(a.get("weight", 1), 1) for a in candidates]
        chosen = random.choices(candidates, weights=weights, k=1)[0]
        self.current_path = chosen["path"]
        self.switch_requested.emit(chosen)
        self._schedule_next()

    def _schedule_next(self):
        lo = max(MIN_HOLD_SECONDS,
                 self.config.get("idle_switch", {}).get("min_interval", 60))
        self.timer.start(lo * 1000)

    def pause(self):
        self.timer.stop()

    def resume(self):
        self._schedule_next()

    def reload(self):
        """重新掃描動畫清單（供導入後呼叫）。"""
        pass  # library.scan() 每次呼叫都重新掃描，無需額外處理
```

### 5.3 拖拽移動與位置保持

- 拖拽期間移動窗口，不放回原位。
- 拖拽釋放後：
  - 保存新位置到 config。
  - 隨機選擇新的待機動畫。
  - 若新動畫 `move=true`，以**當前位置**為新移動起點。
- `stop_idle_move()` 預設**不**回到原點：
  ```python
  def stop_idle_move(self, restore_origin=False):
      self._moving = False
      if restore_origin and hasattr(self, "_move_origin"):
          self.move(self._move_origin, self.y())
  ```

### 5.5 AudioManager
- 統一聲音入口，所有播放都經過 `AudioManager`
- 全局靜音優先級最高
- 音量固定 `DEFAULT_VOLUME = 0.8`
- 短音效用 `QSoundEffect`，長音頻/TTS 用 `QMediaPlayer`

### 5.6 服務管理
- 每個擴展功能做成獨立 `BaseService`
- `ServiceManager` 統一啟動、停止、套用設定
- 設置窗口「擴展」頁根據 `settings_schema()` 動態生成表單
- 移除任何擴展都不影響晴兒核心

### 5.7 待機動畫導入
- 用戶點「導入動畫資料夾」或「導入多張圖片」
- 輸入動畫名稱（預設用資料夾名）
- 自然排序 → 統一轉 PNG → 重命名 `frame_000.png` 起
- 存入 `文檔/animations/idle/<動畫名>/`
- 生成對應的 `anim.json`
- 刷新調度器
- 全程無需重新編譯

## 八、最終提醒

1. **順序固定**：透明窗口 → 動畫行為 → 設置窗口 → 服務擴展 → 優化打包。
2. **晴兒核心只負責顯示、動畫、拖拽、點擊**；所有擴展做成獨立 Service。
3. **動畫放外部資料夾**，每個動畫有獨立 `anim.json`，新增動畫無需重新編譯。
4. **待機動畫隨機選擇**：啟動時、拖拽釋放後都隨機，不固定 idle_standing。
5. **`weight` 越小權重越高**：weight=1 比 weight=3 更常出現。
6. **同一動畫至少持續 1 分鐘**，拖拽動畫不受此限。
7. **拖拽釋放後停留新位置**，不回到原位。
8. **長時間循環動畫首尾幀盡量一致**。
9. **聲音默認靜音或低調**，全局靜音優先，不設音量調節。
10. **問候觸發**：首次啟動後 5 分鐘，當日不重複；聯網用 Gemini 免費層，失敗回退本地；緩存保留最近 7 天。
11. **動態壁紙最難**，放最後做，Windows 優先，其他平台降級。
12. **開發工具**：Windsurf 主力，Codex 輔助疑難與打包，WorkBuddy 備選。
